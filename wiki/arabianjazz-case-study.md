## 썸네일 공식 ⭐⭐

**2가지 스타일 혼용:**

### 스타일 A — Arabic Jazz (재즈 중심)
```
따뜻한 오렌지/황금 색감
+ 사막·모스크·오아시스 배경
+ 악기 연주자 (색소폰, 우드, 트럼펫)
+ "ARABIC JAZZ" 굵은 텍스트 (화면 30~40% 차지)
+ 부제 (The Harmony of Cultures / The Soul of the Desert 등)
```

### 스타일 B — Arabic Hip Hop (힙합 결합)
```
쿨 블루/퍼플/사이버펑크 색감
+ 아랍 전통 의상 인물 + 현대 도시 배경
+ "ARABIC HIP HOP" 굵은 텍스트
+ 에너지 넘치는 구도
```

**핵심 특징:**
- 텍스트 브랜딩 강조 (OdelierJazz와 반대 — 텍스트 없음 vs 텍스트 강조)
- AI 생성 일러스트/이미지 사용
- 장르 텍스트가 클릭율 견인 (검색 유저 직결)
- Hip Hop 스타일 = 젊은 아랍 디아스포라 타겟

## Persian Jazz vs Arabian Jazz 비교

| 항목 | Persian Jazz (Persian Twilight) | Arabian Jazz (Traditional Arabian Jazz) |
|---|---|---|
| 문화권 | 이란 / 페르시아 | 아랍 (이집트·사우디·모로코 등) |
| 핵심 악기 | 타르, 세타르, 페르시아 전통 | 우드 (Oud) |
| 현대 결합 | Deep House, Downtempo | Hip Hop, Chillout |
| 챔피언 조회수 | 11만 | 14만 |
| 챔피언 VPH | 477 | 385 |
| 채널 나이 | 2주 | 4주 |
| 썸네일 | 검은 화면 (없음) | AI 아트 + 굵은 텍스트 |
| 공통 전략 | 장르 태그 결합으로 다중 풀 진입 | ← 동일 |

**결론**: 두 장르 모두 "Middle Eastern Jazz + 현대 장르 결합 = 다중 풀 전략" 동일 패턴  
→ **Middle Eastern Jazz** 통합 카테고리로 묶을 수 있음
