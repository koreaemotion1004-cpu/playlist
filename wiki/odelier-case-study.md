### 썸네일 공식 ⭐⭐⭐

**완전 독보적 비주얼 언어:**

```
1940~50년대 레트로 일러스트 (AI 생성 — 수채화/구아슈 터치)
+ 우아한 여성 인물 (드레스, 레트로 헤어) 중심
+ 흰 고양이 자주 등장 (포근함 시그니처)
+ 따뜻한 색감 (살구 / 갈색 / 로즈 / 크림)
+ 꽃·식물 소품 (화분, 꽃다발)
+ 텍스트 없음 — 순수 일러스트만
```

**핵심 특징:**
- 썸네일만 봐도 "이게 코지 재즈"임을 즉시 전달
- 타 채널과 완전히 차별화된 비주얼 언어
- 고양이 = 포근함·집 = 집중 BGM 사용자 심리 직격

### 10시간 버전 전략 ⭐⭐⭐

```
No Ads (10 Hours) 버전 별도 발행 = 강력한 시청시간 무기
빈티지 소프트 스윙 재즈 No Ads (10H) → 6만뷰 160 VPH
부드러운 스윙 재즈 No Ads (10H)     → 3만뷰 81 VPH
상쾌한 빈티지 재즈 No Ads (10H)     → 1.8만뷰 13 VPH
```

**핵심 인사이트:**
- "No Ads" 자체가 검색 키워드 — 공부/작업 BGM 유저가 일부러 찾음
- 10시간 = 한 번 틀면 하루 종일 → 총 시청시간 폭증
- 같은 음악을 2시간 버전 + 10시간 버전으로 이중 발행 가능
