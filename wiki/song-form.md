# 송폼 구조

## 기본 구조
```
[Verse 1] → [Verse 2] → [Chorus] → [Bridge] → [Final Chorus] → [Outro]
```

## Cafe BGM 구조 (Verse 3 적용) ⭐
```
[Verse 1] → [Verse 2] → [Chorus] → [Bridge] → [Verse 3] → [Final Chorus] → [Outro]
```
- Cafe BGM(Line 1) 전곡 적용 (2026-05-25 확정)
- Verse 3는 **Bridge와 Final Chorus 사이**에 배치
- 역할: Bridge의 직설 고백을 받아 서사를 한 장면 더 전개 → Final Chorus 감정 상승 직전의 디딤돌

## 각 섹션 역할
| 섹션 | 역할 | 줄 수 |
|------|------|-------|
| Verse 1 | 눈에 보이는 장면 (카메라) | 4줄 (AAB는 3줄) |
| Verse 2 | 내면으로 진입 (독백) | 4줄 (AAB는 3줄) |
| Chorus | 감정 폭발 + 훅 (제목 반복) | 4줄 (AAB는 3줄) |
| Bridge | 반전 or 고백 (직설) | 2줄 |
| Verse 3 | 서사 전개 장면 (Bridge 받아 한 장면 더) | 4줄 (Cafe BGM 전용) |
| Final Chorus | Chorus + 감정 한 단계 상승 | 4줄 (AAB는 3줄) |
| Outro | Verse 1 장면 회귀 + 감정 변화 | 3~4줄 |

## 출력 포맷 규칙
- [Verse 1] 뒤에 아무것도 붙이지 않음 (감정%, 장면 설명 금지)
- 제목 뒤에 (라임구조) 괄호 금지
- A, B 라임 마커 금지
- 송폼 태그만 깔끔하게
