이미지 생성 툴(ChatGPT/DALL-E, Midjourney, Nano Banana, Stable Diffusion 등)에 복붙할 프롬프트는 **항상 영어로** 제공한다.

**Why:** 사용자가 명시한 작업 선호 (2026-05-02). 영어 프롬프트가 이미지 생성 모델에서 정확도/표현력이 더 높음.

**How to apply:**
- 썸네일·캐릭터·일러스트·사진 등 모든 이미지 생성 프롬프트 → 영어
- 코드블록 안에 영어로만 작성, 한글 설명은 코드블록 밖에
- 텍스트 합성 가이드(Canva 작업 등)는 한국어 OK — 사용자가 직접 읽는 작업 지시이므로
