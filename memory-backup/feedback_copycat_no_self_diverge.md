사용자가 "카피캣"을 명시한 디자인/이미지 작업에서, 레퍼런스의 핵심 요소(팔레트, 피사체, 타이포, 구도, 테마)는 그대로 따른다. 차별화/채널 정체성 분리/팔레트 변경 등은 사용자가 명시적으로 요청할 때만 제안한다.

**Why:** 사용자가 원하는 변형 수준은 "저작권에 걸리지 않을 정도"로 매우 제한적이며, 본인 채널의 디자인 정체성에 대한 명확한 비전이 이미 있음. 자발적 차별화 제안(예: 단색 다양 → 단일 허니톤, 노인 흑인 → 바 신, SOUL FUNK → HONEY HOUR)은 거부됨. 기존 feedback_soul_funk_reference_only.md(Cafe Mood·Brass 태그 영구 제거, 지정 레퍼런스만 따른다)와 동일한 패턴 — 사용자는 레퍼런스 정공법을 선호한다.

**How to apply:** 카피캣 작업 워크플로우는 (1) 레퍼런스 공통 포뮬러 추출 → (2) 저작권 안전선 안에서 포뮬러를 그대로 적용하되 구체적 expression(개별 인물/포즈/구체적 색상값/구체적 카피)만 새로 생성. 시각적 정체성 차별화 의견은 묻지 않은 한 내지 말 것. 변경이 꼭 필요하다 판단되면 먼저 사용자에게 확인.
