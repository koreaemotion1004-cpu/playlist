Soul Funk Line 2 프롬프트에서 다음 태그·표현은 **영구 금지**:
- `[Late-Night Cafe Mood]` / 텍스트의 `late-night cafe atmosphere`
- `[Restrained Brass Accents]` / 텍스트의 `restrained brass accents`

Soul Funk는 무조건 **BoomSlick / BOOM PULSE / MonoLux** 레퍼런스 채널 정공법을 따른다.
(Cafe Jazz Line 1과의 크로스오버 목적 태그는 사용하지 않는다.)

**Why:** 2026-04-20 사용자 결정. BoomSlick 64만뷰, MonoLux 42만뷰, Mellow_Funk VPH 293 등 레퍼런스 채널은 전부 카페 감성이 아니고 브라스도 거의 없음. 이전 공식의 `[Late-Night Cafe Mood]` + `[Restrained Brass Accents]`는 Line 1 Cafe Jazz와 억지로 섞으려던 잔재였고, 결과적으로 Soul Funk 정체성을 약화시키고 BoomSlick 검색 트래픽 풀을 놓침.

**How to apply:**
- Soul Funk Suno Style of Music 작성 시 두 태그 자동 배제
- 사용자가 "브라스 추가해줘" 류 요청해도 한 번 확인 후 진행 ("레퍼런스 채널은 브라스 없는데 예외로 가시는 거 맞는지?")
- Neo Soul Line 4는 별개 — 이 규칙 적용 대상 아님 (Neo Soul은 Rhodes 중심 모던 프로덕션)
- Gospel Line 3도 별개 — Hammond + Tambourine 유지
- 텍스트 프롬프트 대체 표현:
  - `late-night cafe atmosphere` → `late-night vinyl lounge atmosphere`
  - `restrained brass accents` → 그냥 삭제 (다른 악기로 대체 안 함)
- Mood 태그 대체:
  - `[Late-Night Cafe Mood]` → `[Late-Night Vinyl Lounge Mood]`
  - `[Smoky Vintage Mood]` 유지 가능 / `[Old School Golden Era Mood]`로 강화 가능
  - 추가 시그니처: `[Ultra-Dry Drum Kit]` (BoomSlick 드럼 톤)
